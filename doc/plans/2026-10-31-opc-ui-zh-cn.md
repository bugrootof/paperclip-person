# OPC OS 本地界面汉化验收

日期：2026-10-31。状态：已完成两轮主要操作界面汉化与本地验收；下文保留第一轮记录，最新结果见“第二轮补齐”。

## 实现范围

- 沿用现有 i18next，默认界面语言为 `zh-CN`，英文继续作为回退语言。
- 新增 `ui/src/i18n/board-zh-CN.json`，包含 632 条文案；独立的 board 命名空间保留原有多语言文件的严格校验约定。
- `boardT` 以英文原文为键，关闭句点和冒号的键分隔行为；缺少翻译时显示原文。
- 覆盖侧栏、手机导航、命令面板、公司切换和设置导航、仪表盘、任务列表及筛选、智能体列表、项目、目标列表及详情、费用页常用标签、公司常规设置，以及常用创建表单和引导流程。
- 状态、优先级、目标层级只翻译显示文案。请求中的 `status`、`level`、ID、路由和数据库字段保持原值。公司名称、智能体名称、任务正文以及日志等用户或工具内容不做自动翻译。
- 不新增依赖，不涉及服务端、数据库迁移或 Agent 调度器。

## 使用

运行仓库根目录的 `start-opc.bat`，访问 http://localhost:3100 。已有页面刷新即可载入中文；如仍显示旧资源，使用 Ctrl+F5。

需要英文开发界面时，在 PowerShell 中先设置 `$env:VITE_PAPERCLIP_LOCALE='en'`，再运行启动脚本。此变量由 Vite 读取，生产构建需要在构建前设置。当前不提供界面内语言切换器。
